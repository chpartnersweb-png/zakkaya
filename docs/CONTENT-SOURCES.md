# 掲載内容と素材の出典

## 店舗情報

店舗名、住所、電話・FAX、営業時間、定休日、最寄駅からの徒歩目安、駐車場、支払い方法、Instagram URL、取扱品、サービス、イベントの案内方針は、2026年11月10日のユーザー提供内容に基づきます。

公開用コピーは「その時々のトレンドアイテムが見つかる雑貨店」という方針に沿って編集しています。スクイーズは店舗全体の恒久的な業態名にせず、「今の注目アイテム」だけで紹介します。特集を替えるとメタ説明内の特集紹介も同じデータから変わります。

具体的なイベント日、参加費、商品価格、送料、ポイント付与条件、ラッピング料金は提供されていないため追加していません。

## 生成素材

`src/assets/hero-charms.png` は、ピンクの背景とDIYチャームを題材にした装飾用の生成画像です。実店舗や実際の販売商品の写真ではありません。ヒーロー内の「写真は雑貨のイメージです」の表記は、ユーザーの指示で削除しています。店舗外観を架空に生成していません。

生成方法と最終プロンプトは `docs/GENERATED-ASSETS.md` に記載しています。

## 外部画像・外部サービス

Googleビジネスページの画像を保存する許可はいただいていますが、今回は使用していません。第三者の口コミ投稿画像、他店の写真、検索結果の写真は組み込んでいません。外部検索の情報を店舗の掲載事実の根拠にはしていません。

フォントはGoogle Fonts（Zen Maru Gothic / DM Sans）から読み込みます。読み込めない場合の代替フォントもCSSに指定しています。地図はユーザー提供住所をもとにGoogleマップを埋め込み、別タブで開くリンクも用意しています。

公開URLはユーザー提供の `https://zakkaya.pages.dev/` を採用し、canonical・og:url・構造化データ・サイトマップの参照先を統一しています。

SNS共有画像と構造化データの画像は、現在の特集の先頭にある既存の商品写真（`IMG_1022.JPG`）からビルド時に1200×630pxのJPEGを出力します。ヒーロー用の生成画像を実店舗・在庫の証拠として使用していません。

構造化データの営業時間は提供内容の「全日10:00〜18:00」を通常営業時間として記載し、店舗説明と画面表示に「不定休」を併記しています。個別の休業日は提供されていないため作成していません。価格帯、口コミ評価、緯度経度、商品別の価格・在庫・オファー、未確定のイベント情報は構造化データに追加していません。
