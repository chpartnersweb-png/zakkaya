# 幸町の雑貨屋 LP 更新手順

## ページ構成

1. ファーストビュー：キャッチコピー、雑貨のイメージ写真、Instagramボタン
2. お店の紹介：トレンド雑貨、キーホルダー・めじるしチャーム用DIYパーツ
3. 今の注目アイテム：独立した特集コンポーネント（今回はスクイーズ）
4. サービス・イベント：ラッピング、ポイントカード、佐川急便での発送、イベント情報
5. 店舗情報：営業時間、定休日、電話・FAX、住所、最寄駅、駐車場、支払い方法、地図
6. ページ下部：Instagramへの案内

## 今の注目アイテムを差し替える

`src/data/featured.ts` を編集してください。店舗紹介やページ本体の構成を変えずに差し替えられます。

- `label`：枠の見出し
- `seoSummary`：検索結果やSNS共有説明用の特集紹介。ページの説明文にも自動反映
- `english`：装飾用の英語見出し
- `title`：表示用の見出し（配列の各要素が1行になります）
- `introduction` / `detail`：紹介文
- `photos`：写真・代替テキスト・キャプション・切り抜き位置
- `items`：特集内の3つの紹介項目
- `note`：写真についての補足文

新しい写真を `src/assets/` に保存し、ファイル先頭の import と `photos` を更新します。現在の写真レイアウトはメイン1枚＋サブ2枚の計3枚を想定しています。画像はAstroのImageコンポーネントを使ってWebPと複数サイズをビルド時に出力する構成です。写真をタップすると拡大表示します。

実際の商品写真と確認できない画像に、工場直仕入れ・オリジナル等の個別属性を推測で付けないでください。現在は写真に見えている内容を説明し、各取扱区分は本文で別に紹介しています。

## 店舗情報・Instagram・イベント

`src/data/shop.ts` で編集します。InstagramボタンのURL・文言は共通データを使うため、冒頭とページ下部に同時反映されます。

住所はファイル先頭の `postalAddress`、営業時間は `openingTimes` を編集してください。表示用の住所・時間とSEOの構造化データに同時反映されます。

イベントの開催日・内容が決まったら、同ファイルの `events` 配列に追加します。

```ts
export const events = [
  { date: '確定した開催日時', title: 'イベント名', description: '決定した開催内容' },
];
```

予定がないときは空配列 `[]` に戻します。その場合は「開催日・内容は、決まり次第お知らせします。」と表示されます。

住所を変更するとGoogleマップのリンク・埋め込みURLにも反映します。埋め込みマップはGoogleの外部サービスを利用します。

- `src/pages/index.astro`：全体構成、ヒーロー、お店紹介、サービス、店舗情報、フッター
- `src/components/Featured.astro`：差し替え用の注目アイテム枠
- `src/components/InstagramButton.astro`：共通のInstagramボタン
- `src/components/Icon.astro`：ページ内アイコン
- `src/components/Seo.astro`：canonical・OGP・Xカード・JSON-LDの出力、SNS共有画像のビルド時生成

- `src/data/seo.ts`：タイトル・説明文・店舗などの構造化データ
- `src/pages/robots.txt.ts` / `src/pages/sitemap.xml.ts`：クロール用ファイルの静的出力
- `src/styles/global.css`：ピンク基調の配色、装飾、スマートフォン対応、動きを減らす設定
- `src/scripts/interactions.ts`：スマートフォンメニュー、商品写真の拡大表示
- `src/scripts/motion.ts`：スクロールに合わせた各セクションの表示アニメーション
- `docs/CONTENT-SOURCES.md`：店舗情報と使用画像の出典
- `docs/GENERATED-ASSETS.md`：生成画像の用途、生成方法、最終プロンプト
- `docs/SEO.md`：SEO設定の内容、更新方法、公開後の作業

## ヒーローの画面サイズ対応

ヒーローはユーザーの指定により、左右に余白を設けた角丸の元のデザインに戻しています。左右の余白はPCで20px、スマートフォンで10pxです。高さ、文字サイズ、内側余白、スクロール案内の位置も全画面化の変更前に戻し、訪問時のアニメーションは維持しています。

「写真は雑貨のイメージです」の表示はユーザーの指示で削除しています。画像が生成素材であることは素材管理ドキュメントに記録しています。

## ページ訪問時・スクロール時のアニメーション

ヒーローのアニメーションは `src/styles/global.css` の `entrance-*` で調整できます。

- 背景画像：少し拡大した状態から、約1.6秒で元のサイズへ
- ヒーロー内：導入文、見出し、紹介文、Instagramボタンの順に、少し下からフェードイン
- ヘッダー、スクロール案内：控えめなフェードイン

本文のアニメーションは `src/scripts/motion.ts` で管理しています。各要素が画面に入る直前に、一度だけ下からフェードインします。商品写真やサービス項目は最大0.18秒の時間差を付け、スマートフォンでは移動距離を小さくしています。既存の写真の傾きはそのまま維持します。

本文はCSSで事前に非表示にしていません。JavaScriptやアニメーションAPIが利用できない場合も通常表示されます。キーボードでリンク等にフォーカスした場合は表示を優先し、ページ途中へのリンクやスクロール位置の復元時には、最初から見えている本文を再度隠しません。

端末で「動きを減らす」が有効な場合は、ヒーロー・スクロールのアニメーションを無効にします。閲覧中に設定を切り替えた場合も、実行中の動きを止めて通常表示に戻します。

今回の追加にあたり、新しいパッケージの追加は行っていません。ユーザーの確認方針に従い、実装後のビルド・型チェック・ブラウザー確認は実施していません。

## 開発

既存のAstroプロジェクトと依存パッケージを利用しています。開発サーバーを起動するときは `AGENTS.md` の指定に従います。

```sh
npm run dev -- --background
```

サーバー管理は `npx astro dev status` / `npx astro dev logs` / `npx astro dev stop` を使用してください。

ユーザーの指示により、今回の実装後のビルド、型チェック、ブラウザー確認、リンク確認は実施していません。開発サーバーも起動していません。変更はローカルソースに保存しており、公開・デプロイは行っていません。
