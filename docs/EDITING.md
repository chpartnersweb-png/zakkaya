# 幸町の雑貨屋 LP 更新手順

## ページ構成

1. ファーストビュー：キャッチコピー、生成した透過雑貨装飾、Instagramボタン、スクイーズ特集への案内
2. お店の紹介：トレンド雑貨、キーホルダー・めじるしチャーム用DIYパーツ
3. 今の注目アイテム：「世界一のスクイーズが作れる」を中心に紹介するスクイーズ特集

6. ページ下部：Instagramへの案内

## 今の注目アイテムを差し替える

`src/data/featured.ts` を編集してください。店舗紹介やページ本体の構成を変えずに差し替えられます。

- `label`：枠の見出し
- `seoSummary`：検索結果やSNS共有説明用の特集紹介。ページの説明文にも自動反映
- `english`：装飾用の英語見出し
- `title`：表示用の見出し（配列の各要素が1行になります）
- `introduction` / `detail`：紹介文
- `photos`：写真・代替テキスト・キャプション・切り抜き位置
- `items`：特集内の3つの紹介項目
- `note`：写真についての補足文

新しい写真を `src/assets/` に保存し、ファイル先頭の import と `photos` を更新します。現在の写真レイアウトはメイン1枚＋サブ2枚の計3枚を想定しています。画像はAstroのImageコンポーネントを使ってWebPと複数サイズをビルド時に出力する構成です。写真をタップすると拡大表示します。

実際の商品写真と確認できない画像に、工場直仕入れ・オリジナル等の個別属性を推測で付けないでください。現在は写真に見えている内容を説明し、各取扱区分は本文で別に紹介しています。

## 店舗情報・Instagram・イベント

`src/data/shop.ts` で編集します。InstagramボタンのURL・文言は共通データを使うため、冒頭とページ下部に同時反映されます。

住所はファイル先頭の `postalAddress`、営業時間は `openingTimes` を編集してください。表示用の住所・時間とSEOの構造化データに同時反映されます。

イベントの開催日・内容が決まったら、同ファイルの `events` 配列に追加します。

```ts
export const events = [
  { date: '確定した開催日時', title: 'イベント名', description: '決定した開催内容' },
];
```

予定がないときは空配列 `[]` に戻します。その場合は「開催日・内容は、決まり次第お知らせします。」と表示されます。

住所を変更するとGoogleマップのリンク・埋め込みURLにも反映します。埋め込みマップはGoogleの外部サービスを利用します。

## ヒーローの画面サイズ対応

2026年11月17日の添付参考画像に合わせ、ピンク、白黒チェック、白・ピンク・黒の縁取り、ステッカー風の見出し、鮮やかな透過雑貨装飾を組み合わせたデザインに変更しています。ヒーローだけでなく、お店紹介・特集・サービス・アクセス・Instagram案内も同じデザインで統一しています。

ヘッダーとヒーローは一体のファーストビューとしてデザインしています。ヘッダーは通常フローの白い帯から、ヒーロー上部に浮かぶ角丸のナビゲーションへ変更しました。半透明の白背景、細い枠とピンクの影を使っています。固定追従ではなく、ページ先頭への絶対配置です。

ヒーローの高さはヘッダー分を差し引かない `100svh` です（`100vh` のフォールバックあり）。旧 `--header-height` とコンテナーの高さに比例して文字を縮める `cqh` の指定は廃止しました。本文の上部にナビゲーション用の領域を確保し、画像や本文全体をヘッダーの下へ押し縮めない構成です。

内側のピンク面は `.hero-panel` で表示します。四隅すべてを角丸にし、PCでは上12px・左右16px、スマートフォンでは上8px・左右10pxにチェック柄の余白を設けています。浮かぶナビゲーションの外側にも角丸と枠線が見える構成です。

ピンク面には `src/assets/hero-dense-charms.png` の1枚画像を配置しています。添付参考画像のように雑貨を周囲へ密集させた新しい生成画像で、既存の透過装飾とは別の素材です。画像はパネル内にクリップし、中央を基準に画面比率に合わせてトリミングします。本文・ボタンはHTMLのまま重ね、従来の透過装飾も継続して使用します。

ヒーロー内の文字と余白は画面の幅・高さに合わせて調整します。上部の透過装飾は右上へ配置し、ナビゲーションと中央の見出しを避けています。高さ600px以下の横長画面では本文を2列配置にし、ナビゲーションもコンパクトに切り替えます。高さ660px以下の縦長画面では本文の間隔を調整します。極端に高さが低い画面や拡大表示では本文領域をスクロール可能にし、文字とリンクにアクセスできるようにしています。スマートフォンメニューも画面高に合わせて内部スクロールできます。見出しと説明は画像内の文字ではなくHTMLで表示します。

スクイーズのメインコピーは「世界一のスクイーズが作れる」です。`src/data/featured.ts` の見出しと紹介文、項目の並びを作る楽しさを中心に変更し、ヒーローにも特集リンクを設けています。Instagramボタンは `label` を渡すと、その箇所の文言だけ変更できます。料金・予約方法・開催日時などの未提供情報は追加していません。

「写真は雑貨のイメージです」の表示はユーザーの指示で削除しています。画像が生成素材であることは素材管理ドキュメントに記録しています。

## ヒーローのボタン

`src/pages/index.astro` の `.hero-actions` にスクイーズ特集とInstagramのリンクをまとめています。幅1025px以上では、同じ幅・高さのカプセル形ボタンを横並びにします。幅1024px以下では見出しとボタンを中央の1列にそろえ、ボタンは同じ幅・高さの縦並びにします。左アイコンと本文を共通の列でそろえています。ヘッダーのメニュー切り替えも1024pxに統一しています。

高さ600px以下かつ幅600px以上の横長画面では、見出しの右にボタン2つを縦並びで表示します。幅599px以下・高さ500px以下の横長画面では、見出しの下に小さなボタン2つを横並びにします。スクイーズは黄色、Instagramはローズ色です。右矢印は削除し、左側には花とInstagramのアイコンを配置しています。共通のInstagramボタンからも右矢印を削除しています。

## ページ訪問時・スクロール時のアニメーション

ヒーローのアニメーションは `src/styles/global.css` の `entrance-*` で調整できます。

- 上部の透過装飾：少し拡大した状態から、約1.4秒で元のサイズへ
- ヒーロー内：導入文、見出し、2つのボタンの順に、少し下からフェードイン
- ヘッダー、スクロール案内：控えめなフェードイン

本文のアニメーションは `src/scripts/motion.ts` で管理しています。各要素が画面に入る直前に、一度だけ下からフェードインします。商品写真やサービス項目は最大0.18秒の時間差を付け、スマートフォンでは移動距離を小さくしています。既存の写真の傾きはそのまま維持します。

本文はCSSで事前に非表示にしていません。JavaScriptやアニメーションAPIが利用できない場合も通常表示されます。キーボードでリンク等にフォーカスした場合は表示を優先し、ページ途中へのリンクやスクロール位置の復元時には、最初から見えている本文を再度隠しません。

端末で「動きを減らす」が有効な場合は、ヒーロー・スクロールのアニメーションを無効にします。閲覧中に設定を切り替えた場合も、実行中の動きを止めて通常表示に戻します。
